# Minik Ressam

Huawei tablet için çocuklara adım adım kâğıda çizim öğreten uygulamanın güncelleme dosyaları.

- `index.html`: uygulamanın içeriği (çizimler, kalemi tutan el, ekranlar)
- `version.json`: sürüm numarası ve doğrulama özeti

Tablette kurulu uygulama, internet varken bu dosyalara bakar ve yeni sürümü kendisi indirir.

## Kullanılan hazır içerik

Kalemi tutan el, Microsoft'un **Fluent Emoji** setindeki "Writing hand" çiziminden uyarlanmıştır
(kalem rengi, silgi, ahşap uç ve kazak kolu eklendi).
